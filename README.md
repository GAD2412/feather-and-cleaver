Feather & Cleaver is an original, offline-playable HTML5 Canvas Thanksgiving turkey escape game. Dash, hide in cover, toss corn decoys, outmaneuver a multi-state Farmer AI, and dodge cast-iron ovens and carving knives across five escalating stages from the Harvest Farmyard to the Freedom Woods Gate.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

To generate the submission output bundle (`out/game/`, `out/screenshots/`, and `out/dossier.json`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
